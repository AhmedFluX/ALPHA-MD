🔥 ABOUT ALPHA-MD

ALPHA-MD is a WhatsApp automation project built with Node.js and Baileys, designed with a modular architecture, customizable settings and a premium command experience.

«"NOT JUST A BOT — IT'S THE ALPHA EXPERIENCE."»

⚡ CORE FEATURES

Feature| Description
⚡ Command System| Prefix-based commands
🎨 Hybrid Menu| Stylish command menu
🔌 Plugin System| Modular plugin architecture
💬 Auto Reply| Configurable auto replies
🛡️ Group Tools| Group management modules
📊 Database| JSON-based storage
🔄 Reconnection| Connection recovery
🌐 Pairing Website| Integrated pairing interface

🚀 INSTALLATION

git clone https://github.com/AhmedFluX/ALPHA-MD.git

cd ALPHA-MD

npm install

npm start

⚙️ CONFIGURATION

Configure these environment variables in your hosting panel:

OWNER_NUMBER=923XXXXXXXXX
PAIRING_ACCESS_KEY=YOUR_PRIVATE_SECRET
PORT=3000

Never publish your real credentials or WhatsApp session files.
